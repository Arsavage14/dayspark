# DaySpark — Daily Task Doer

A colorful, mobile-friendly daily task app. Tasks are saved by date in the browser on your device. You can revisit previous days, mark tasks complete, edit/delete tasks, and export/import a backup.

## Put it on your Android phone (recommended: GitHub Pages)
1. On a computer or phone, sign in to GitHub and create a **public** repository named `dayspark`.
2. Upload all four files from this folder (`index.html`, `manifest.json`, `sw.js`, `icon.svg`) to the repository's main/root folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
5. Wait for GitHub to publish the site. Open the Pages URL it gives you in Chrome on your Android phone.
6. In Chrome, tap **⋮ → Add to Home screen** (or **Install app**, if shown). The DaySpark icon will appear on your home screen.

## Data and backups
- Your tasks are stored in this browser on this device, separated by date.
- Use the ↥ button to download a JSON backup. Use the ↧ button to select and restore a previously downloaded backup.
- Save backups somewhere safe. Clearing browser site data, changing browsers, or changing phones can erase or strand the local data.
- This version does not sync between devices or accounts. Keep a backup before changing phones.
